# How to give this kit to Claude Code

## Files

- `PROMPT_FOR_CLAUDE_CODE.md` — full implementation brief. This is the authoritative prompt.
- `references/01-landscape-minimal.png` — landscape layout and color reference.
- `references/02-portrait-compact.png` — primary portrait and touch-card reference.
- `references/03-landscape-editorial-inspiration.png` — secondary art direction only; do not copy photographs or invented details.

## Recommended workflow

1. Download and unzip this kit on your Mac.
2. Copy the folder `claude-code-routine-kit` inside the root of your existing My Planning code repository (do not overwrite any existing files).
3. In a terminal, open Claude Code from that repository's root, or attach all four files directly in a Claude Code session that supports attachments.
4. Paste the following launcher prompt:

   > Read `claude-code-routine-kit/PROMPT_FOR_CLAUDE_CODE.md` completely and inspect its three reference images under `claude-code-routine-kit/references/`. Then implement the requested iPad-first Routine dashboard redesign in this existing codebase, preserving all data and other tabs. Verify both iPad orientations with real screenshots. Stop before production deployment and ask for my approval.

5. Share with me Claude Code's actual landscape and portrait screenshots before agreeing to deployment. We can iterate on the result.
