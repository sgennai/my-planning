## Exposure

Corrected **at fetch time** by the CDN (`bri`), not by a CSS filter at render
time — one filtered element per tile would each become its own compositing
layer, which an iPad 7th gen pays for. Stock photography arrives at every
exposure; these measured between 5 and 210 mean luminance as delivered. The
`bri` values below bring them into one band so the photograph reads as
texture and the tile's title stays the loudest thing on it.

`sat=-8` throughout, to sit with the dark palette.

## Re-fetching or adding

```sh
BASE="https://images.unsplash.com/photo-<id>?fit=crop&fm=webp&sat=-8&bri=<bri>"
curl -o public/routine/<key>.webp       "$BASE&w=900&h=460&q=70"
curl -o public/routine/<key>-thumb.webp "$BASE&w=200&h=112&q=62"
```

Then add the key to `AVAILABLE_PHOTOS` and to a group in `PHOTO_GROUPS`
(`src/routine/photo-manifest.ts`). `photo-files.test.ts` fails if a declared
key has no file, if a file has no thumbnail, or if an image ships that no key
declares.

If you swap an asset, re-measure its mean luminance and pick a `bri` that
lands it near 72 — otherwise one frame will either vanish into the panel or
shout over its own title.
